Silkscreen Graphics in Fusion

Silkscreen artwork is optional. It can make a board more personal or visually distinctive, but functional labels, polarity marks, connector identification, and revision information take priority.

Prepare an SVG

Simple vector artwork usually transfers more reliably than a detailed photograph or multicolor image. Begin with an SVG that uses bold shapes, limited detail, and line widths compatible with the selected manufacturer's current silkscreen capabilities.

Before import:

  • remove background rectangles and other unwanted shapes;
  • convert text to vector paths if the lettering must remain exact;
  • simplify gradients, multiple colors, clipping masks, and CSS-based styles;
  • check that small gaps and narrow strokes will survive scaling;
  • retain the editable source SVG.

The ME5305 logo below shows a color rendition and a black-and-white rendition for silkscreen preparation. Use the black-and-white version as the import starting point, and check its fine gaps and strokes at the intended board size.

Insert the SVG in Fusion Electronics

Current Autodesk documentation gives this path in an open electronics document:

  1. Open the 2D PCB document.
  2. On the Design toolbar, choose Place → Insert SVG Image.
  3. Select the SVG file.
  4. In the Insert SVG panel, choose the target layer, whether to import strokes only, a group name, and a scale factor.
  5. Place the graphic by coordinates or by clicking in the canvas.

Fusion currently defaults a PCB SVG to layer 21 Silkscreen Top and imports it as a movable group. Use the actual top or bottom silkscreen layer required by the design. Autodesk notes that multiple colors, backgrounds, CSS styles, text, low-precision geometry, and highly complex images can produce unexpected results.

Scale and Place the Artwork

Keep the graphic inside the board outline and away from pads, solder-mask openings, test points, fiducials, and areas hidden by components. Check it at the final physical dimensions rather than judging only from a zoomed display.

Do not apply a blanket manual mirror operation to bottom-side artwork. Use Fusion's layer and view behavior, then verify the generated bottom-silkscreen output in the same viewing convention used by the Gerber viewer and manufacturer.

Verify the Output

  • Artwork is on the intended silkscreen layer.
  • Scale, stroke width, and spacing meet the selected manufacturer's current limits.
  • No important portion overlaps pads, mask openings, fiducials, or board edges.
  • Functional labels remain readable and visually dominant where needed.
  • Top/bottom orientation is correct in the exported Gerber viewer.
  • The manufacturer's upload preview matches the intended result.
  • The local SVG is packaged with the source and has useful alt text in the published guide.
